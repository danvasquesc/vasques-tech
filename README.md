# 📂 Vasques Tech

**Vasques Tech** é um site profissional criado para **apresentar e divulgar** meus serviços de manutenção e suporte técnico de notebooks, com foco em soluções acessíveis, práticas e eficientes. <br>
Além de funcionar como meu catálogo digital de serviços, o site também serve como canal de contato e direcionamento de orçamentos, facilitando o atendimento aos clientes e centralizando todas as informações sobre o trabalho que realizo.
O projeto reflete minha **identidade profissional como técnico e desenvolvedor**, sendo totalmente responsivo, funcional e otimizado para a web.

## Estrutura do projeto
A estrutura do projeto foi pensada para garantir organização e manutenção simplificada. <br>

Dentro da pasta `src`, o conteúdo está dividido por tipo de recurso - CSS, JavaScript e imagens, mantendo uma separação clara entre responsabilidades. <br>

Tanto em `css` quanto em `js`, há duas subpastas principais:

- `global/`, que concentra os estilos e scripts de uso geral, aplicados em todo o site. Aqui ficam elementos essenciais como o layout base, variáveis, resets e funções reutilizáveis.

- `pages/`, que contém os arquivos específicos de cada seção (como “Início”, “Serviços”, “Sobre” e “Contato”). Essa divisão permite que cada parte do site tenha suas próprias regras e comportamentos, sem interferir nas demais.

Essa estrutura modular foi adotada para facilitar futuras manutenções e expansões. Caso novas páginas ou funcionalidades sejam adicionadas, basta criar novos arquivos dentro da pasta correspondente, mantendo o código limpo e organizado.
